2026-10-21 npm auditの取得結果は npm-audit.json。報告された既知脆弱性0件。これは未知の問題の不存在や包括的な侵入検査を意味しない。依存のバージョン/lockは変更していない。

## 確認範囲

静的アプリ・同一オリジンのデータアセット・Workerで計算。入力条件/結果を外部APIに送る処理、アカウント、解析タグ、外部フォント/スクリプトを追加していない。研究出典リンクを利用者が開く場合は外部サイトへ移動する。配信事業者は通常のHTTPアクセス情報を扱うため、ホスティングを含めて「一切情報が送信されない」とは表現しない。

Reactのテキスト表示を使用し、原ラベルをHTMLとして解釈しない。任意ファイルのインポート機能なし。数値入力と実行来歴を境界で検証。CSVは検証済み非負整数・分数文字列と固定単位だけで構成し、利用者のラベル文字列や数式を出力しない。引用符だけをCSV数式注入対策として扱わない。列を拡張するときは再レビューする。

Workerは要求IDで古い応答を拒否、取消時terminate、Blob URLは再実行時に解放する。工程9/10の寿命テストを保持。OSによるタブ全体の強制終了はアプリ内で必ず検知できるとは限らず、1,000回実行の低メモリ実機は公開前の未解決事項。

## 配信ヘッダー

public/_headersはCSP default/script/worker/connectをselfに限定し、object/base/frameを禁止。styleのunsafe-inlineは既存React/SVGのインラインstyleと両立するため必要であり、scriptには許可しない。nosniff、no-referrer、カメラ/マイク/位置情報禁止を設定。BlobダウンロードはCSP下で実測する。noindexは検索抑制でありアクセス制御ではない。

秘密鍵・APIトークンをアプリへ渡す機能はない。公開前にGitHub側のsecret scanningとリポジトリ履歴の専門的監査を所有者が確認する。正規表現の簡易スキャンのみで秘密情報不存在を保証しない。HTTPS用のテスト秘密鍵は/tmpだけに生成しコミットしない。
