## 数理・データ監査

independent-report.json が機械可読な証拠。原CSVの254,165 bytes、SHA-256・MD5、全3,882件の1対1対応、1,930件の同値行保持を確認。2014年1,687件・2015年2,195件。409条件（全体、年、年×処理、年×Round、48年×区画、336年×区画×Round）を原CSVから選択し、基準ネットワークと部分集合を独立に照合した。

全2,682試行について抽出原番号、順序、PCG語数、全ペア重み、原ラベル、両側の相手数、固定Connectanceと保持率を一致確認。PCG公式6語に加え9シード/系列条件・4棄却条件を検証。R=1000の先頭100試行はR=100と同一。7指標の平均・標本分散・平方根表現・type7分位点をPython Fractionで照合した。R=1の分散は不定であり0ではない。

10件fixtureのk=0〜10の全1,024部分集合を列挙し、各ペアの未確認確率 C(N-m,k)/C(N,k) に基づく期待値と完全一致。k=5の期待ペア数は143/36。これは理想的固定件数抽出の性質であり、現実の観測努力量の妥当性を証明しない。Python検算は独立したコードであり、外部専門家による査読ではない。

## 性能と残る問題

browser-report.json：既定100回2.55秒、1,000回21.18/22.14秒。1,000回の初回UI転送は約221KBで全86MBを転送しない。環境共有・測定条件が異なる第9工程との速度差を最適化前後の比較とは呼ばない。今回は数理コードの最適化なし。

node-timing.json：初回ロード132ms。100回は計算2.52秒・追加結果検証0.22秒・出力準備0.52秒、1,000回は26.41秒・2.69秒・6.15秒（シリアライズ5.87秒、SHA-256 0.27秒）。Node SSRプロセスの累積最大RSSは約1,004MiB。これはブラウザやiPadのメモリ測定ではなく、低メモリ端末での成功を保証しない。全試行保存契約を維持するため回数を黙って減らさない。低メモリ端末は100回から確認する。

独立監査で数値不一致は発見されなかった。WebKit起動は実行環境のライブラリ不足でBLOCKED、iPad実機・スクリーンリーダー・低メモリ実機はNOT TESTED。一般公開のGO判定は出さない。科学的注意事項・元データ・計算来歴を変更していない。
