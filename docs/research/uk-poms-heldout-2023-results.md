# ECO MIRROR｜UK PoMS公式実測：2023年ブラインド予測の初回実証

**作成日：2026-11-05。対象：英国PoMSの計画型1km FIT Count（2017–2023）。**  
本書は研究用の独立したバックテスト結果であり、生態系全体の健康度・崩壊確率・日本の公園への予測精度を実証するものではない。

## 1. データと権利

- 出典：UK Pollinator Monitoring Scheme (2026). *Flower-Insect Timed Count data from the UK Pollinator Monitoring Scheme, 2017–2023*. NERC EDS Environmental Information Data Centre. DOI https://doi.org/10.5285/d706088c-9d48-4be5-b156-6ed6ad5e0618
- ライセンス：Open Government Licence。PoMSはUK Centre for Ecology & Hydrology（UKCEH）・JNCC等の支援による共同事業であり、調査した多くのボランティアに謝意を表する。利用には公式の指定Acknowledgementも参照すること：https://ukpoms.org.uk/data
- 取得元：https://data-package.ceh.ac.uk/data/d706088c-9d48-4be5-b156-6ed6ad5e0618
- CSV（計画型1km）のSHA-256：29d3deb757c053774c26ece0a7683081a4b4fe81d9497877fe1179f232182e52
- 別の「public FIT count」のCSVは、Windows-1252の混在があるためUTF-8だけの読み込みが失敗した。字コードのフォールバックを追加して13,457行を読み込めることを確認。計画型1kmは3,053行。合計16,510行。
- **重要：** ダウンロードZIP全体のSHA-256は複数回取得で異なったが、ZIP内の1km CSV SHA-256は一致した。包材全体でなく計算対象CSVのハッシュで版を照合する。

位置情報の生データは本研究用PR・実行結果へ一切アップロードせず、公式から一時取得して集計値のみを保存する。

## 2. 評価目標と漏洩対策

**予測対象：** 2023年に観測された固定1km区画の、1区画・1年あたりの「10分FIT Countに記録される昆虫訪花回数の平均」。**昆虫個体数、送粉成功、生態系健全性とは異なる。**

- 学習：2017～2022年の3,053件中2,502件（1km型のみ）。
- 完全に隠す年：2023年の551件。
- 2023年の実測結果をモデル係数やハイパーパラメータ選択に使わない。
- ハイパーパラメータ \`k\` は2020、2021、2022年のローリング予測だけで選定。候補0,1,2,4,8,16の中で8を選んだ。
- 地点は \`(country, location_code)\` で区別。観測のなかった年を0件の調査とみなさない。訪花回数0の実施済み調査は元のまま保持。
- 検証対象2023年の87地点中、81地点はそれ以前の年にも記録があり、6地点は未観測（国平均などへフォールバック）。

## 3. 予測モデル

区画s、2023年を予測する時点より前の当該区画の記録がn_s年、過去の区画年別平均が bar_y_s、同じ国の過去の区画年別平均が bar_y_country とすると、

**縮約予測**：

\[
\widehat{y}_{s,2023}
=\frac{n_s\bar y_s+k\bar y_{\mathrm{country}}}{n_s+k},
\qquad k=8.
\]

現在の研究における「階層的な情報共有」の単純・決定的な基準モデル。負の二項分布・気象・花量・検出確率は**まだ組み込んでいない**。同じデータから、全地点過去平均、国ごとの過去平均、同地点の直近記録、同地点の過去年平均とも比較。

## 4. 2023年の実測に対する誤差（87地点）

MAEは平均絶対誤差、RMSEは平均二乗誤差平方根。単位は「10分訪花カウントの区画年平均における回数」。

| モデル | MAE | RMSE | RMSE²に基づくGlobal比Skill |
|---|---:|---:|---:|
| 全地点の過去平均 | 5.71610 | 6.85423 | 0 |
| 国ごとの過去平均 | 5.08912 | 6.66275 | 0.05509 |
| 同地点の直近記録 | 5.17353 | 7.59723 | -0.22855 |
| 同地点の過去年平均 | 4.92243 | 6.67103 | 0.05274 |
| **地点平均＋国平均の縮約（k=8）** | **4.83073** | **6.28763** | **0.15849** |

縮約モデルは、このテストで全地点平均よりMAEが約15.5%小さかった。RMSE²の改善も15.85%。予測が優れているという主張は **このデータ・年・予測目標・検証設計の範囲に限定**する。別年・他国・異なるデータ収集方法への一般化は証明できていない。

前年持続のRMSEは全体平均より悪く、過去をそのまま未来に延長する方式の弱さが表れた。

2017–2023の観測件数（1km）：336,347,489,212,551,567,551。1km調査の実施地点数（各年）：71,63,63,57,65,80,87。2023年には昆虫が0回だった実施済みカウントが、全期間で合計271件ある。元記録を欠測に変換していない。

## 5. 「将来の悪化確率」としての試験は失敗

実用性を試すためだけに、**「2023年にその地点の過去年平均より訪花カウント平均が30%超低い」**という暫定イベントを作った（生態学的な悪化基準として未承認）。過去の予測誤差分布を用い、区画ごとのイベント発生確率を出してBrierで評価。

| 指標 | 実際の結果 |
|---|---:|
| 過去年による校正対象 | 182地点年 |
| 2023年の評価対象 | 70地点 |
| 実際に閾値を下回った割合 | 34.286% |
| モデルの平均予測確率 | 49.464% |
| 簡易ベースラインの平均予測確率 | 46.196% |
| **モデルのBrierスコア** | **0.245260** |
| **過去頻度ベースラインのBrier** | **0.239491** |
| Skill（正なら改善） | **-0.02409** |

**判定：確率予測モデルはベースラインを下回ったため、実用採用しない。** これは「現行の単純な校正法では足りない」という結果であり、時間・気象・花量の関係が存在しないことの証明ではない。

## 6. 利用者に追加観測を求めない改善策

1. ECO MIRRORが公式観測データを自動取得し、地域・期間・調査プロトコル・生息環境・分類群を自動判別する。
2. 最初は**地域＋過去地点情報の縮約モデル**を訪花記録の研究用ベースラインとして採用。世界のどこでも使えると断定しない。
3. 次に、元CSVにすでに存在する調査時期、花量、日照、風、対象植物を使う**観測条件補正モデル**と、外部の気象・土地被覆データを加えた**前年時点で利用可能な説明変数だけによる真の未来予測モデル**を作り、別年テストで比較する。
4. 目標の「悪化確率」は暫定閾値と校正モデルが不合格。追加の利用者調査に頼らず、公式の年別データを使った確率校正（季節・地域・対象昆虫群別）とモデル選択を内部実装する。
5. 真の状態が識別不能な地点、海外学習モデルを日本へ適用できると示せない地域では、**環境負荷の公開データ分析**だけを提示し、悪化確率は \`NOT_ESTIMABLE\` とする。
6. 予測結果、データ版、モデル版、作成時点を保存し、後年の公式観測データでBrierやMAEを再評価する。既存の予測は書き換えない。

## 7. 再現用コード・テスト

- \`scripts/research/poms_inspect.py\`：公式配布ZIPのスキーマ/年/行数/欠測/CSVハッシュ。
- \`scripts/research/poms_heldout.py\`：生CSVの固定ハッシュ確認、ローリングパラメータ選択、2023年の完全ホールドアウト、MAE/RMSE/Brierの集計。
- \`.github/workflows/research-poms-access.yml\`：公的ZIPをGitHub Actionsランナー上で取得し、監査と2023年検証を実行。成果物 \`poms-inspection.json\`, \`poms-heldout-2023.json\` を集計結果だけ保存。
- \`python scripts/research/poms_heldout.py --self-test\`：合成データで予測時点の漏洩を防ぐテスト。
- \`python scripts/research/poms_heldout.py --out poms-heldout-2023.json\`：公式データによる試験。

**影響範囲：** 研究専用ファイル・CI・文書の追加と、ファイルの文字コード/ZIPハッシュ検査の必要最小限の修正だけ。既存データ、TypeScript計算コア、Worker、画面、lockfile、公開設定には変更なし。mainへマージ・一般公開しない。

## 8. この結果が示さないこと

- ECO MIRRORが日本の公園・森林・河川の将来リスクを正確に推定できたという証拠
- 30%の訪花カウント低下が生態系崩壊を意味するという証拠
- 局所絶滅や受粉成功、全生態系健康度の予測
- 気候シナリオを使った真の将来予測の完成
- 観測しなかった昆虫が不在という証拠

これらは **未検証** と明示したままにする。
