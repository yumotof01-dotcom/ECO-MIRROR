# ECO MIRROR｜実データによる12式の監査と改善計画

**2026-11-05｜研究段階。将来の生態系悪化確率はまだ検証できていない。**

対象はMoss–Evans (2022) の英国実験の固定CSV、3,882件・7列。原本DOI：https://doi.org/10.25405/data.ncl.17430548.v1（CC BY 4.0）。データの使用と来歴は data/README.md に従う。12式の定義は observation-aware-forecast-model-v0.1.md にある。

## 1. 実際にした計算

Node研究スクリプト **scripts/research/benchmark-observation-models.mjs** は、原CSVのSHA-256を照合し、以下を改変なしに算出する。
- 全257ペア、1回のみのペア118、3回以下181、2014/15共通ペア62、記録のある年×Plot×Round単位321。
- イベントを一様・非復元抽出した場合の超幾何式による理論期待ペア数。
- 750試行・seed=16923921で、「イベントを個別抽出」と「年×Plot×Roundの調査単位をできるだけまとめて抽出」を、**同じイベント数**に合わせて比較。後者は最後の調査単位のみ必要な件数まで部分抽出する説明用の設計差実験であり、野外調査の検証済みモデルではない。
- 前年の区画別「記録行数」から次年の「記録行数」を予測する単純ベースラインの比較。これは**生態系将来状態の予測精度ではない**。
- 1回の0/1検出から占有確率と検出確率を同時に識別できないことの代数的テスト。

## 3. 数式ごとの可否と、利用者に追加観測を求めない解決策

| 式 | 実データでの結果 | ECO MIRROR側で解決する方法 |
|---|---|---|
| 1 時間あたり訪花率 | 現CSVでは努力量が不明で不可 | 10分固定の公式調査データを自動採用。現地1件は記述結果に留める |
| 2 負の二項カウント | 未推定・未検証 | 公的な反復・ゼロを含むデータでPoisson/NB等を比較して事前学習 |
| 3 占有・検出確率 | 単回観測では識別不能 | 既存の公的反復調査を利用して分類群・季節別のモデルを別途検証。移転不能なら保留 |
| 4 有限記録のペア検出 | 実行・理論期待値との整合を確認 | 調査単位ごとの抽出感度も表示、一様抽出の仮定を明示 |
| 5 階層的な情報共有 | 処理群別の単純縮約は全体平均に劣る | 環境・地域・プロトコルにより対象を絞り、ベースラインを改善したときのみ採用 |
| 6 時系列状態変化 | 現CSVでは適切に学習できない | 公式長期時系列であらかじめ学習し、将来年を隠した検証を実施 |
| 7 将来悪化確率 | 必要な教師ラベル・基準・検証済みモデルなし | 対象指標と期間を固定し、外部テストで検証できてからのみ表示 |
| 8 推定可能性の判定 | 可能 | 欠落時は NOT_ESTIMABLE と理由、取得済み公的データを示す |
| 9 Brierスコア | 妥当な予測確率と未来の正解がなく不可 | 予測を版付き保存し、後日の公的記録との照合を自動化 |
| 10 Skillスコア | 9と同じ理由で不可 | 同じ地点・期間の単純予測と比較して採用を判断 |
| 11 確率的更新 | 正式モデル未学習で不可 | 公的データの版更新で再学習、過去の予測記録を変更しない |
| 12 情報価値による追加観測選択 | 校正済み生成モデルがなく不可 | 情報価値式は保留し、利用者への追加調査要求ではなく自動データ源探索と不足理由の提示 |

## 4. データ不足でも利用者に負担を増やさない仕組み

**自動取得できる情報**：現在地（本人の明示操作で選択した場所）、土地被覆・緑地変化・気象・日射・干ばつ要因などの公的な環境記録。出典・時刻・解像度・欠測を保持する。

**先行研究で学習・適用検証する情報**：季節変化、分類群ごとの検出可能性、訪花活動と環境条件の統計的関連。地域差の補正と外部地域での予測テストが必要。英国の係数を日本へそのまま転用しない。

**補えないもの**：その地点で未確認の個々の訪花関係、観測実施不明の回を0にすること、受粉の成功、局所絶滅を断定すること。公的情報でも不明なら **推定不能を正しく表示**する。

**表示を二分**：A「公開環境データから分かる外部環境負荷」とB「独立検証済みモデルが適用できる場合の生態指標悪化リスク」。Aを生態系悪化確率と呼ばない。

## 5. 公式長期観測データとの次の比較

英国UK PoMSの公式EIDCデータ（2017–2023 FIT Counts、2026公開、OGL）：https://catalogue.ceh.ac.uk/documents/d706088c-9d48-4be5-b156-6ed6ad5e0618 。一人で行える10分の訪花カウントで、地点・日時・花・昆虫・気象の情報がある。一般参加型と計画型1km調査を区別する必要がある。

**今回、公式ZIPのバイナリ取得に環境制約があり、PoMS行データによる係数推定・年度外テストは実行できていない。** 取得できた際は①列・欠測・ゼロ・努力量の監査→②地点/年を分離した学習/検証→③同季節平均対NB対階層状態モデルの比較→④確率の校正→⑤未使用地域でのテストの順とする。適用条件を満たすまで実用リスク値を出さない。

## 6. コードへの影響範囲と再現

追加ファイルは本資料、研究用Nodeスクリプト、独立した研究CIワークフロー。元CSV、データ契約、既存計算コア、PCG32、React画面、package.json/lock、公開設定は不変。mainへは統合していない。

- 実データベンチマーク: node scripts/research/benchmark-observation-models.mjs --check
- 小規模な数式単体確認: node scripts/research/benchmark-observation-models.mjs --self-test
- 前段の独立Python監査: python scripts/research/future_risk_audit.py --check

研究CIは出力JSONを成果物として保存する。CI成功は科学的な将来予測精度の証明ではない。
