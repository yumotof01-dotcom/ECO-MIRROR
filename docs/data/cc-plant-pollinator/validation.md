## 監査と独立した照合

主監査はPython標準ライブラリのcsvで行い、`audit.py` と生成物を保存。別にpandas 2.2.3でCSVを読み、次の8項目を独立したgroupby・重複判定等で照合した。

1. 2配布版の表全体の一致。
2. 3,882行・7列の形状。
3. 7列同値行を一律削除した場合に減る1,930行。
4. 原分類ラベルの異なり数（植物20・昆虫104）。
5. 年×Roundの全件数。
6. 年×Plotの全件数。
7. 年×Plot×Roundの全件数。
8. 著者の別の区画年集計ファイルのVisitsとの48組全件一致。補助資料のYearを1→2014・2→2015と明示的に対応させた場合に一致し、総和も3,882。

この照合は計算結果の再現や将来の指標の妥当性の検証ではなく、元記録の監査集計の確認。pandasはアプリ依存・監査プログラムの依存には追加していない。

## 監査プログラムの再現性と失敗時の確認

| 確認 | 結果 |
| --- | --- |
| 固定2入力で再実行 | profile.json、counts.md、taxa.mdの全バイトが保存済み成果物と一致 |
| 入力を1改行分変更して実行 | SHA-256不一致で失敗し、出力ディレクトリを作成しない |
| 監査前後の元CSVのSHA-256 | 2ファイルとも不変 |
| 件数の整合 | 年、年×処理、年×区画、年×回、年×区画×回、Basic_Type、植物辞書、昆虫辞書の各総和が3,882 |

監査プログラムは原CSVを読み取るだけで、取得・正規化・学名修正・重複削除・ランダム抽出を行わない。生成物を変更すると再現一致の確認が変わるため、修正時は監査プログラムから再生成する。
