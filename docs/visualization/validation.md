## 任意のブラウザQAを再実行

プロジェクトの依存を変えず、外部環境にPlaywrightと互換Chromiumがある場合に実行する。通常のCIには追加のブラウザ依存を要求しない。

```bash
# PlaywrightがNodeのモジュール探索パスで見つかる環境
node scripts/visualization/browser-check.mjs
# 必要ならECO_MIRROR_BROWSER_PATHで実行ファイルを指定
# ECO_MIRROR_VISUAL_QA_OUTPUTで記録先を別ディレクトリに変更可能
```

この環境では既設のPlaywrightを使い、通常のダウンロード先が利用できなかったためDebianの互換Headless Shellを一時展開して検証した。アプリの依存/ロックファイルへブラウザ用パッケージを追加していない。

## 残る確認・科学的制約

Chromium以外のブラウザ、実スマートフォンのタッチ、スクリーンリーダーの実機、OS強制カラーの実機は未検証。密な関係には線の交差があるため、ノード選択・検索ハイライト・任意の線絞り込みで確認する。全124ラベルの俯瞰には縦スクロールが必要。

未確認リンクは自然界で消滅した関係ではない。全記録は完全な真値ではなく、原ラベル数は確定種数ではなく、訪花数は受粉効率や重要度ではない。英国実験から日本の草原を直接評価しない。反復は未来予測ではない。科学的な未知情報・元データの制約は工程5資料のまま。

重大な既知の数値不一致はない。通常アプリへの実行/状態/結果接続は工程9に残した。出力、AI、バックエンド、一般公開、デプロイは今回の範囲外。
