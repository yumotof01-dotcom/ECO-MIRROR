# データ選定と出典管理

## 現在の状態

第3工程でCC-plant-pollinatorの指定CSVを調査し、用途を限定して採用した。3,882行・7列、大学保管v1のCC BY 4.0、指定GitHub版と大学版の記録内容・行順の一致を確認した。第4工程で大学保管v1の原CSVを無変更で同梱し、取得情報・ライセンス証拠・全行の正規化・監査・型安全なローダーを実装した。第6・7工程の計算と第8工程の比較表示は、第9工程で操作画面と出力へ接続済み。 元データを装うサンプルや架空の種名は画面に用意しない。

採用条件と監査結果は [調査報告](data/cc-plant-pollinator/README.md)、出典・版・ハッシュ・利用条件は [manifest.json](data/cc-plant-pollinator/manifest.json)、工程4の処理規則は [normalization.md](data/cc-plant-pollinator/normalization.md) に記録する。原名モードで全行を保持し、分類名・重複・未確認の調査実施情報を暗黙に修正しない。

Web of Lifeは候補の入口。個別のデータID、植物・昆虫の対象範囲、記録単位、ライセンス、再配布条件は未確認であり、採用を確定していない。植物と鳥等のデータを、昆虫のデータとして使わない。

## 工程3で残す調査項目

| 項目       | 確認すること                                                       |
| ---------- | ------------------------------------------------------------------ |
| 出典       | データID、提供元URL、元論文・DOI、著者、データの版                 |
| 対象       | 植物・昆虫の分類群、種と形態種の区別、調査範囲                     |
| 観測方法   | 訪花の定義、調査方法、観測努力、季節・時刻・地域の情報の有無       |
| 粒度       | 個別イベント、集計行列、二値、回数、頻度、標準化された重みのどれか |
| 行列の意味 | 行と列の分類群、値の単位、0と欠測の違い、負値・非数・重複          |
| 利用条件   | 個別データのライセンス、引用指定、加工・同梱・再配布の可否         |
| 適合性     | 目的に合う理由、実現できない観測条件、データ固有の限界             |

未確認の項目を「確認済み」としない。記録時点では不明と書き、採用判断に必要な条件が満たされないデータは保留する。

## 工程4で残す来歴

取得日時、取得URL、元ファイルのハッシュ、変更していない原本、正規化スキーマの版、正規化の各処理、検証記録を対応付ける。保持・同梱は利用条件の範囲に限定する。

0と欠測の変換、重複の統合、分類名の変更、行列の転置などは暗黙に行わない。入力から利用可能なデータへ至る処理を再実行できるようにする。

指定CSVの具体的なフィールド・配置・正規化ルールは、実物の確認に基づく設計としてnormalization.mdにまとめた。工程4の具体的な型・CLI・検証・再現性の規則は [implementation.md](data/cc-plant-pollinator/implementation.md)、結果は [phase4-validation.md](data/cc-plant-pollinator/phase4-validation.md) に記録した。未確認の努力量・同定・実施情報は補完しない。
