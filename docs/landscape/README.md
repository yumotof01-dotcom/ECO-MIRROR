# ECO MIRROR 3.0｜自然の限界点 × 100の条件 × 自然の橋

**現在：第0工程／数理と科学的制約の仕様確定。** 実際の地図分析やアプリ表示は次工程以降。

## 初めて見る人向けの説明

- **何を見る？** 公開地図で確認できる緑地の配置と、離れた緑地同士のつながり。
- **100通りとは？** 動物の移動条件や緑地の分断を変えた100種類のモデル実験。未来を100%当てる機械ではない。
- **限界点とは？** その100条件の中で、つながり指標がとくに大きく低下する場所。実際の絶滅や崩壊とは別。
- **自然の橋とは？** 限られた改善候補から、複数条件の下で「つながり」を改善しやすい地図上の場所。生物の移動や工事が実際に成功する証拠にはならない。
- **使う人に必要な作業は？** 原則、地域選択だけ。追加の野外観測は求めない。

## 第1工程の実装順序

1. 公式地図データの入手可能性・ライセンス・引用・凡例と分類精度を確認する。
2. 実在する2km四方の範囲と外周バッファを設定し、取得・CRS・ハッシュを検証する。
3. 植生候補の抽出を行い、4/8近傍によるパッチの違いを調べる。
4. L1～L3を独立したTypeScriptの純粋計算として実装し、手計算と固定再現テストを通す。
5. 土地被覆に由来する結果と、移動能力を仮定した結果をUI・正式結果で区別する。
6. その後に100条件・限界点・橋候補の研究へ進む。

既存の訪花記録抽出モデル、正式結果契約、乱数系列、Reactの通常画面はこの段階で変更しない。
