## 2. 初回検証で発覚した本当の計算上限の問題

新宿4km四方160,000セルの初回試験では、440条件中430件だけ成功。分散型の仮想植生除去50%×4近傍で**3,541個のパッチ**に分裂し、既存の最大3,000パッチの安全制限に引っかかったことが原因。計算できなかった10件を成功・ゼロ扱いせず、不完全として記録する処理は機能していた。

**最小限の修正**：安全制限を最大4,000パッチに変更。実際の3,541パッチを計算し、4,001以上は引き続きMODEL_LIMITとして拒否する回帰テストを追加した。異常系試験の模擬チェッカーボードに縦の連結があったテスト生成ミスも修正した。4km地図の境界について、固定の2km表記も実際の窓サイズを表示するよう訂正した。

**再実行の結果：大型実地440/440条件と40/40曲線が成功、独立監査にも合格。** Linuxランナーで大型ベースライン440件に約10.57秒、最大RSS約269MiBを使用。4km版の全結果SHA256：15a79c2ae986e2f15a70769f6c2e69e975721d8856ea1d64301669c5f292b5f7。

2km版の新宿データの全440条件結果SHA256：fd2306dd2a7c8f43cef061c352ed7510635e8b1fdf9299103ef6acb351696e29は既存工程の結果と一致。後方互換性の確認にもなっている。

**科学上の注意**：大型4kmの条件ではモデル急変の暫定判定0件で、以前の2kmで見えた1件と異なる。しかし、両者は分母となる解析面積も異なる別のウィンドウであり、科学的に「緑地崩壊の限界点がなくなった」等と比較してはならない。外側の生息地まで考慮する適切なバッファは別途設計・検証が必要。

## 3. 異常入力と大量の合成数理テスト

- 現実の新宿2kmの分類マスクから、256か所を1セルずつ反転してSHA256改ざん検知を確認。加えて、出典URL、旧版、ライセンス、帰属、元データハッシュの偽装、寸法、不明値等12種類。計**268種類の改変入力を拒否**。
- 合成の8×8小格子5,000個＝**32万個のテスト用セル**を決定的に生成して、PC範囲、面積上界、λ単調性、パッチ数と面積の整合など**25,001項目の不変条件**を検証。
- 400×400の極端に分断された合成パッチと、100万セル超の合成データは安全上限で判定保留。
- 正規のゼロ（対象領域が全て非植生）と、地図の欠損を区別。異常系の完全性を通すために欠測をゼロ埋めしない。

これらは数理・入力安全性のテストであり、合成グリッドを自然界の観測として扱わない。

## 4. 異なるコードによる独立監査

各地域について、元分類・派生マスクのハッシュ、6×440条件の全数、40本の変化曲線、選んだ96地点の42,240件の面積/PC差分/条件対応/分位点/順位/4近傍・8近傍パッチ連結状態をPythonでクロスチェックした。さらに各地域で選定した標本条件の**改善前後PCとパッチ数をPythonで独立実装して再計算**。6地域の独立監査は6/6成功した。

第1〜4工程に限ったCLIであり、既存の3,882件イベント解析は従来の回帰テストで別途確認。元CSV、固定の乱数系列、正式結果契約、既存の画面を変更していない。

## 6. 再現・監査の入口

最新の研究ブランチをGit履歴込みで取得し、既存CIの npm ci と npm run check を実行。

- 公式の2km窓：python scripts/landscape/ingest_worldcover.py --site shinjuku --out /tmp/crop.json
- 440条件：node --experimental-strip-types scripts/landscape/run-worldcover.mjs /tmp/crop.json /tmp/baseline.json
- 橋候補：node --experimental-strip-types scripts/landscape/run-bridges.mjs /tmp/crop.json /tmp/baseline.json /tmp/bridges.json
- 独立監査：python scripts/landscape/audit_real_results.py /tmp/crop.json /tmp/baseline.json
- 独立橋監査：python scripts/landscape/audit_bridges.py /tmp/crop.json /tmp/baseline.json /tmp/bridges.json
- 異常入力監査：node --experimental-strip-types scripts/landscape/stress-adversarial.mjs /tmp/crop.json
- 4km大型では上記の取得コマンドに --size-cells 400 を追加し、440条件と独立監査を行う。

GitHub Actions workflow：landscape-stress-regions.yml（6地域の行列ジョブ＋大型窓）。各ジョブの生データ由来JSON、440条件の全結果、橋の全結果、性能ログを一時的なWorkflow Artifactとして保存。
