# 第1工程：実装状況と実データ取得ゲート

**状態：純粋計算コアの最初の実装。実在する地図タイルの取得・公式分類の変換・現地検証は未実施。**

## 実装済み

- 新規の独立した src/features/landscape/core に、メートル単位の正方格子、4/8近傍の植生候補パッチ抽出、面積・重心、重心距離を用いた仮説的な接続性PC計算を追加。
- データセットID・版・SHA256の存在を要求し、未知セル・不正CRS・不正格子・無効な移動スケールを判定不能として返す。
- 旧観測イベントエンジン、旧RunResult、PCG32、画面、元CSVは変更していない。
- 数式の入力は **すべて合成テストデータ**。地図上のハナバチの実際の移動確率を推定した結果ではない。

## 注意：v1のモデル上の近似

パッチの**重心間距離**を使った距離減衰型の構造的接続性を計算する。第0工程の d_eff（地表抵抗を含む移動コスト距離）を一般に計算できるものではない。抵抗面、地図セル間最小コスト、最適回廊は未実装。移動スケールλは**仮説入力**であり、対象ハナバチの実測値とは限らない。

現行の結果は STRUCTURAL_ONLY だけ。実際の移動を検証済みの ECOLOGICALLY_VALIDATED には絶対に昇格させない。

## 未完了・次のゲート

1. JAXAまたはESA公式地図の利用条件と入手経路を検証し、正式な地図データのバイト列を取得する。
2. 元データの正しい分類凡例と投影座標、対象2km領域と適切な外側バッファを確認する。
3. 公式ラスタを変換するアダプタを追加し、実際のソースSHA256を**バイト列から計算**する。現在の型検証はハッシュの文字形式を調べるだけで、入力が正規データだと証明しない。
4. 未知セル・欠測の割合、分類誤差、区域外切断を評価する。未確定セルがある場合は判定保留とする。
5. 公式地図の小領域でパッチを抽出し、出典と位置を再現可能に報告する。
6. 生物の移動特性・地表抵抗を外部研究で検証するまで、移動経路や橋の有効性を現実の事実として表示しない。

## 科学的・技術的制限

- 初期コアはJGD2011日本平面直角座標系 EPSG:6669～6687 の正方格子を想定する。別のCRSや回転したラスタ、緯度経度格子は変換が必要。
- 解析対象の外側バッファとデータ権利は呼び出し側で確認する必要がある。現状のコアだけでは適切なバッファや許諾を自動確認できない。
- 最大100万セル、最大3000パッチのガードを置く。実用性能とメモリ使用量は実データで別途測定する。
- 100通りのシナリオ、限界点、橋候補は**第1工程のコアに含めない**。第0工程の数学参照テストは別に保持する。
- 現在の synthetic-test-only は検証専用であり、公開画面へ現実の土地被覆として表示しない。
