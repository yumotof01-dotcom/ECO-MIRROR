# 第9工程：公開前の機能統合版

既存のデータローダー・単一/反復計算・第8工程の比較図を接続する。新しい数理モデル・データ・乱数・統計エンジンは作らない。外部API・利用者アカウント・バックエンド・デプロイは追加しない。

## 利用手順

1. 完全なGit履歴を持つ第9工程ブランチで`npm ci`、`npm run dev`。ホームから「シミュレーションを始める」。
2. 年・Plot・処理・年別Roundを明示的に選択する。初期値は両年、全24区画、全4処理、各年の全Round、50%、seed 42、反復100回。
3. 有効な入力で実行する。データ/来歴を検証してからWorker内で計算する。読み込み・計算中は架空の数値や推定進捗を表示しない。
4. 結果の実行時条件、主要6指標、単一試行と反復全体の統計を確認する。試行番号で保存済みのネットワークだけを切り替える。
5. ネットワークの共通スクロール、検索、フォーカス、凡例と詳細で関係を確認する。図の絞り込みは正式指標を変更しない。
6. 「保存ファイルを準備」で全試行をWorker内で検証・正規化・ハッシュ化する。正式JSON・来歴JSON・CSVの3リンクから保存する。ブラウザが保存を受け付けたか、端末の保存先を確認する。
7. 「この条件で再実行」は結果に結合された元条件を復元する。「条件を変更」は編集画面へ戻る。

条件・結果はタブのメモリ内にある。ページ間移動では保持し、再読み込み・タブ終了で失う。保存ファイルのブラウザへの取り込みは今回実装しない。オフラインの再計算確認は[出力資料](exports.md)を参照。

## 入力と状態

シードとRは文字列で編集し、空欄・指数・符号・小数・空白を整数へ黙って変換しない。シード0〜4294967295、R=1〜1000。割合だけは0〜100の整数スライダー。単一と反復R=1は異なる契約で、反復R=1の分散/SDはnull。空配列は全選択ではなく入力エラー。

形式が正しくても元記録のない条件はempty_scope。元CSVに行がないことは、実施済み訪花0件の証拠ではない。正の比較基準から0%残す場合は正常なsuccess。UIのcancelledを正式RunResultへ加えない。[全状態と競合対策](state-transitions.md)を参照。

## データフローと性能方針

明示条件→要求ID付き新規Worker→既存ローダーのハッシュ/全3,882件検証→既存core/runSingleTrialまたはrunRepeatedTrials→完了結果の検証→全RunResultをWorker内に保持。画面へはヘッダー（比較基準/summary含む）・分布用の小さなスカラー・現在の1試行を渡す。全1,000試行のネットワークをReact stateへ持たない。

既存`features/simulation/run.ts`はローダーを呼ぶ画面非依存ラッパー。Workerはloading/runningの段階と読込失敗を区別するためローダーを先に呼び、同じ公開全件コアへ検証済みデータを渡す。数式・PCG・抽出・統計を複製しない。ローダー/ラッパー/コアの元コードは変更していない。

試行取得は全結果の再送・再実行をしない。`NetworkTrialView`は`kind`で識別したヘッダー+実試行であり、不完全なtrials配列を正式RunResultと偽らない。基準ノードの座標は工程8のまま再利用する。

同期コアには完了試行数のコールバックがないため進捗は段階表示のみ。Worker.terminateによる取消は同期処理中も機能する。失敗時にRを減らす・失敗試行を除外する・成功へ補正する処理はない。測定とメモリ上の限界は[性能記録](performance.md)。

## 統計表示

正式summaryの平均・標本分散・標本SD・min/max・type 7の2.5/50/97.5%分位点を7指標すべて表示する。表示の小数はBigInt分数から丸め、正式値に書き戻さない。保持率SDはパーセントポイント。分散の単位は元指標の単位の二乗。分数の正確な値はセルのtitleと正式JSONにある。SDは被開平数を正確に保存する。

ペア数分布は整数1組幅、実値のmin〜max。保持率分布は0〜100%の5ポイント幅、左閉右開で最後のみ100%も含む。ビン所属は分数に対する整数演算。縦軸は試行数。横スクロール可能なSVGと度数表を用意し、元統計を再計算/変更しない。

## 科学的な解説

比較基準と標本の実数値を短い決定的テンプレートへ埋め込む。未確認のペアは自然界から消滅した関係ではなく、訪花は受粉成功の証拠でもない。原ラベルは確定種、記録数は個体数ではない。反復の分位範囲はこの抽出モデルに条件付けられ、生態系の95%信頼区間ではない。英国実験から日本の草原を評価しない。全48区画年を独立反復とみなさず、記録のない15群の調査実施状態を推測しない。

研究ページと別来歴にMoss & Evans (2022)、大学保管v1 DOI、CC BY 4.0、加工内容、元著者の承認を意味しない旨を示す。説明用のホームSVGは明記し、実分析図へ合成データを渡さない。
