# 操作仕様

- 下部：割合0〜100%、シード0〜4294967295、反復1〜1000、単一/反復。既存の厳密な文字列検証を使用。空欄・指数・符号・小数を0に補正しない。
- 詳細条件：観測条件リンクからdialog。Escapeまたは閉じるで戻る。native dialogで背面へのフォーカス移動を防ぐ。実行すると結果へ移動。
- 実行：水滴はbutton。Enter/Spaceでも動作。loading/runningは二重実行不可。既存状態通知と中止ボタンを使用。
- ノード：クリック/タップ、Enter/Space、全ノードのnative selectで選択。背景クリックで解除。詳細の相手ボタンで相手へ切り替え。
- キーボード：図内の矢印で原ID順に移動、Home/Endで端へ。＋/−で拡大縮小、0でリセット。フォーカスノードが画面外なら自動で中心へ移す。
- パン：Pointer Eventsによるドラッグ。5pxを超える移動は選択にしない。2本指の中点と距離を使うピンチでは選択を抑止。倍率0.65〜4。
- ホイール：図にフォーカスがある場合、またはCtrl/Metaを押した場合だけズームし、それ以外はページスクロールを妨げない。
- 比較：全観測/抽出後/差分は同じ基準座標。差分は基準にあるが抽出後0のペア。全基準ペアのデータを残す。
- 検索：原ラベルの文字列一致でハイライト。接続線のみのフィルターは表示だけを変更。全結果・指標は不変。
- 記録：既存の全統計・二部比較・JSON/来歴/CSV。現在実行だけのメモリ保持。再読込・タブ終了で失う。永続メモや履歴機能は追加しない。
- 条件変更時の取消、旧結果ラベル、実行条件復元、旧非同期応答排除は既存ExecutionClient/Providerをそのまま使用。
