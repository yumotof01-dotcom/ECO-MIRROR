# 性能・再現性

共有Linux環境、Node24.19.0、Chromium154。固定CPU・実機RAM・ピークRSSを管理したベンチマークではない。browser-report.jsonが今回の実測。

| 50%・seed42・R100 | 約1.19秒 | 8,728,268 bytes |
| 50%・seed42・R1000 | 約11.55秒 | 86,277,392 bytes |

R1000の正式SHA-256は083873fbd56b8b3a7fb30c876a86c878252d18583b906c4354bfe85286c29ab8。既存実装の値と完全一致。50%単一はc7a9d45480d42834bdee569d94af0441b4e78a95e8d0452b552a63fcfb42fe45。R100は723647a1068328e6b038de381a25b1cb42ba4190d62d9ab374c974e95b2f1880。

全試行と大きいJSONはWorker側に保持。UIへ渡すR1000データは約223KB相当。パン・ズーム・検索・比較切替・試行切替で計算readyが増えず、指標と元座標が不変なことを検証。座標は基準IDに対してmemo化し、背景は独立した静的SVG。force simulation、連続アニメーション、大きいbackdrop-filter、外部画像通信はなし。

メインJSは約357.7KB（gzip約113.3KB）、CSS約54.4KB（gzip約12.8KB）。元版は約340.5KB/32.8KB。依存追加なし。小さい増加はUI・操作・森林SVGの追加による。既存の共有環境測定と同程度のR1000時間で、今回の検証では重大な計算退行は観測しなかった。厳密な速度向上・全端末の性能保証とはしない。

最大heartbeat間隔は自動操作・画面作成・ダウンロードも含む参考値であり計算専用指標ではない。Worker全結果・Web Cryptoの全ArrayBuffer・Blobを扱うため低メモリ実機での成功は保証しない。取消時Worker0・URL0、再実行時旧URL解放を検証。Rや結果を黙って減らさない。
