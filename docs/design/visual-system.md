# 森林と水膜の視覚系

森林はForestBackground.tsxで独自制作したSVG。遠景の幹、手前の幹、林冠、地面、シダと光のレイヤーで奥行きを示す。外部画像・フォント通信なし。UIの描かれた参考画像は背景にもアセットにも使用しない。

背景は装飾であり、英国調査地の写真・植物ノード・測定値ではない。粒子や架空の関係線を背景へ混入させない。ネットワークは別のSVG。

暗緑の連続面、淡いアイボリーの文字、植物の葉形と昆虫の円形・羽、観測記録の薄い関係線。水滴は非対称のSVGパスを持つ通常のbutton。詳細は有機的な輪郭を持つHTML aside。大きなぼかし・force simulation・毎フレームの配置更新は使わない。

小画面では詳細を図の下へ流し、条件はスクロール可能なdialog。図の表示変換だけを変え、座標・指標を端末幅で変更しない。厳密二部図・統計表には内部スクロールを残す。

第三者画像のライセンス追加は不要。データのCC BY 4.0と既存の第三者ソフトウェア帰属は維持。参考画像との主な差は、写真ではなく様式化されたベクトルの森林、写真のないノードである。
