# 科学的解釈と限界 1.0.0

## 1. 言えることの範囲

「この英国実験の選択範囲N行を比較基準として、本仕様の固定k行を残した場合、基準で記録されていたL₀ペアのうちLペアが抽出内でも確認できた」と記述できる。

反復は同じ比較基準とモデルに条件付けられた記録部分集合の変動。結果の版・出典・選択範囲・指定割合と実現件数・シード組・反復数・指標の分母を添える。全観測記録の有限性、原ラベルを使うこと、受粉成功を測っていないことも説明する。

## 2. 言えないこと

| 誤った読み替え | 理由と使用する表現 |
| --- | --- |
| 「50%抽出だから実際の調査時間が半分」 | 実績時間・訪花の時間順がない。記録の指定割合である |
| 「見えないリンクは自然界で消滅した」 | 抽出記録に含まれないだけ。未観測と不在を区別できない |
| 「昆虫が減少/絶滅する未来を再現した」 | 行の非復元抽出であって個体群動態・種の除去モデルではない |
| 「全3,882行が生態系の真の関係全て」 | 地域・期間・方法・同定精度に制約された観測標本 |
| 「104種の昆虫」 | 原ラベルの異なり数。未確定・複合名・異名・綴り候補を含む |
| 「訪花があったから受粉成功」 | このCSVに有効花粉移動・受精・各訪花による結実の証拠はない |
| 「0の相手数だから野外で孤立」 | 選択/抽出した記録に相手がいないことだけを表す |
| 「15組は調査済みで訪花0」 | 実施・努力量の台帳がなく未実施や欠落と区別できない |
| 「保持率が高い処理ほど健康」 | 原頻度、サイズ、選択範囲で値が変わる。健全性尺度ではない |
| 「英国データから日本の再生草原を判定」 | 場所・実験条件・植生・期間が異なる |
| 「2.5–97.5%の範囲＝生態系の95%信頼区間」 | 抽出モデルに含めていない不確実性を反映しない |

## 3. イベントを等確率に選ぶ仮定

等確率はこの有限リストに対する数学的な仮定。自然界の全訪花が同じ確率で記録されていたとは仮定しない。固定件数の選択は調査回内の集中、季節、観測者、天候、空間、採集・同定の偏りを再現しない。原順は日時順とみなさない。

頻出ペアは、その行が複数あるため少なくとも1行が残りやすい。一律のペア抽出や分類名の統合は別の分布になる。元の同値行を残す一方、それらの二重入力有無が確定していないという不確実性も残す。

行単位の単純無作為抽出は基準モデルとして採用するが、「現実的な観測過程を検証済み」と呼ばない。グループ単位・層化・観測努力を考慮したモデルには、それぞれ別の根拠、単位、分母、版、検証が必要。

## 4. 48区画年と処理比較

元論文は24区画、4処理各6反復の無作為化ブロック設計を記す。同じ番号の区画・同じ処理が両年に現れることは工程3監査で確認済み。したがって48区画年を48の独立反復とはみなさない。ブロック割当や年をまたぐ依存を推測で埋めず、処理効果の検定・因果推論・空間的独立性をこのMVPに含めない。

区画年で別々にモデルを実行することは記述上可能だが、区画年をプールして一つの独立標本と解釈する根拠にはならない。大きさ・原頻度・分類群・努力量が異なる範囲間を、同じpというだけで公平な生態学的比較としない。

## 5. 未確認事項と今後の条件

| 未確認の情報 | 今回の対応・将来必要なもの |
| --- | --- |
| 日付・時刻、Roundの実日との対応と不連続の理由 | 元の年別ラベルを保持。実施ログが必要 |
| 各回の実際の観測分数、15組の実施状態 | null/effort unknownを保持。努力量台帳が必要 |
| ブロック割当、空間・年をまたぐ依存 | 独立性を仮定せず、設計資料・反復測定モデルを別途検討 |
| 分類名候補の承認・再同定・複合ラベルの内訳 | 原名モード。根拠付き・版付き対応表なしに統合しない |
| 同値行が二重入力かどうか | 全行保持。個体や日時などの証拠なしに削除しない |
| 実地の時間短縮・検出確率と行抽出の対応 | 同一視しない。別の観測過程の研究・データが必要 |

## 6. 一次資料と設計判断の区別

- Moss & Evans (2022), [元論文・Methods](https://www.frontiersin.org/journals/plant-science/articles/10.3389/fpls.2022.826205/full), DOI `10.3389/fpls.2022.826205`：英国実験の方法・区画・処理と、訪花/種子研究の文脈。MVPの抽出モデルを著者が検証したと主張しない。
- [大学保管v1](https://doi.org/10.25405/data.ncl.17430548.v1)と[工程3監査](../data/cc-plant-pollinator/README.md)：対象CSVの利用条件・原分類ラベル・件数・未知情報。
- [bipartite公式networklevel](https://cran.r-project.org/web/packages/bipartite/refman/bipartite.html#networklevel)：二値Connectanceとweighted指標を区別するための参照。ECO MIRRORの分母固定は本プロジェクトの目的に合わせた判断。
- [PCGの著者による参照](https://www.pcg-random.org/using-pcg-c-basic.html)と[Rのtype 7説明](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/quantile.html)：数値手法の定義。これらの手法が生態学的妥当性まで保証するわけではない。

抽出単位、半数切上げ、固定分母、PCG32、系列オフセット、反復上限、分位点の選択は**ECO MIRRORの設計判断**。既存研究の推奨値や自然法則と区別し、変更時は仕様の版を更新する。
