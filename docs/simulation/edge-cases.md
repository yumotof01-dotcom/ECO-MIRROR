# 境界条件と失敗の扱い 1.0.0

数学上の空集合、正しい抽出で0件、未実行、取得失敗、調査実施不明を区別する。後工程はこの表を受け入れテストにする。処理の順序は**全ファイル検証→全パラメータ検証→選択→N=0の判定→k→抽出→集計**。N=0でも不正なシード・割合・Rを先に検出し、入力不正を空スコープで隠さない。

## 1. 割合と標本サイズ

| 条件 | 結果と解釈 |
| --- | --- |
| N>0,p=100 | k=N、原順で全件、乱数消費0。全指標が参照と一致、Lost=0、保持率100% |
| N>0,p=0 | k=0、`success`、空標本。観測ラベル/ペア0、Lost=L₀、保持率0%、固定Connectance0、相手数/重み0。実際の訪花0件を意味しない |
| N=0 | `empty_scope`、eligible_record_count=0。試行しない。抽出件数・実現割合・参照/比較結果・サマリーはnull、trialsは空配列 |
| N=1,p=49 | k=0。有効な空標本。自動的に1件へ増やさない |
| N=1,p=50 | k=1。0.5件は切り上げる。指定50%に対し実現100%を別に示す |
| N=1,p=100 | k=1、全件一致 |
| N=3,p=50 | k=2。確率的に1/2件を振り分けない |
| N=7,p=99 | k=7。100%以外でも全件になることを示す |
| Nが小さい | 計算は定義どおり。標本が小さいことと実現割合を明記し、数値から強い生態学的結論を出さない |
| 異なるpが同じkになる | 同一D・試行シード組なら同じ標本・指標になる。指定pの違いは設定として残る |

0%は将来のUI/APIで許可する。現在の未接続フォームの最小1%はこの工程で変更せず、実装時に範囲と説明文・テストを合わせる。単一コアの工程6で画面接続を先行しない。

## 2. 選択と実施不明

| 条件 | 動作 |
| --- | --- |
| years=[2014]にRound2又は6 | `INVALID_SELECTION`。2014のRoundを振り直さない |
| years=[2015]にRound8又は9 | `INVALID_SELECTION` |
| 片年だけなのに他年のRoundキーがある | `INVALID_SELECTION`。古いフォーム状態を黙って使わない |
| 2年に共通のRound一覧だけが与えられる | `INVALID_SELECTION`。必ず年別キーを要求 |
| 値・キーが欠ける、配列が空、重複、不正型 | `INVALID_SELECTION`。空を全選択へ変換しない |
| 順序だけ違う同じ選択値 | 同じ正規選択・スコープになる |
| 正しいPlotとTreatmentに該当する元行なし | `empty_scope`。処理を割り当て直して行を作らない |
| 2014/Plot3/Round1だけを選択（元Treatmentに合う条件） | `empty_scope`。元CSVに行なし、実施・努力量不明 |
| 一部の選択グループに行なし、他には行あり | 行のあるイベントだけでNを定める。行なしの診断情報を保持し、0イベントを追加しない |
| 元は行のあるグループだが、Sには残らなかった | 今回の抽出の結果。元の実施不明15組へ追加しない |

`no_record_groups` は記録のない元の年区画回を表す。相手数やペア重みの数学的0を使うことと、調査実施不明を確認済み訪花0へ変えることは別である。

## 3. 分母と反復

| 条件 | 動作 |
| --- | --- |
| L₀=0で保持率を求める純粋な指標検証 | null、`zero_reference_pairs`。0/0を0又は100にしない。実行APIではempty_scope |
| a₀b₀=0で固定Connectance | null、`zero_reference_nodes`。実行APIではempty_scope |
| S空、D非空 | 固定分母は正なので保持率/固定Connectanceは有効な0。active方式は分母0でnull（MVP出力しない） |
| R=1の反復モード | 平均・min/max・分位点はその試行値。標本分散/SDはnull、`insufficient_trials` |
| R≥2で同値結果 | 分散/SDは有効な0。同じ試行結果を削除しない |
| R=0、負数、小数、1,000超 | `INVALID_REPETITIONS` |
| 試行の途中失敗・欠損 | 実行全体のerror。欠けた試行を除いた「成功した100回」等を返さない |

## 4. データ・乱数・数値の不正

| 検出内容 | コード・対応 |
| --- | --- |
| 取得失敗、原本/正規化のハッシュ不一致 | 既存ローダーのエラーを保持。空配列へfallbackしない |
| 原番号の順序違い・重複・欠落 | `SOURCE_ORDER`。ソートで修復せず、入力を確認 |
| SにD外のID、同じ原IDの二重採用 | `NOT_A_SUBSET`。同値内容でも別原IDなら許可 |
| pの不正型、小数、範囲外、非有限値 | `INVALID_RATE` |
| master seedの範囲外・不正型 | `INVALID_SEED`。uint32への暗黙の巻戻しは禁止 |
| tの不正型・0〜999外 | `INVALID_TRIAL_INDEX` |
| mの不正型・範囲外 | `INVALID_BOUND`。m=1は0、消費0 |
| 負の重み、非整数件数、新規ペア・新規ノード | `INVALID_NUMERIC_RESULT`又は`NOT_A_SUBSET`として失敗 |
| 非既約/分母0の分数・負の分散 | `INVALID_NUMERIC_RESULT`。clamp・丸め補修はしない |

エラーにはステージ、該当する条件/試行/原番号、原因を含める。実データの分類名、日時、努力量を推測で直して計算を継続しない。
