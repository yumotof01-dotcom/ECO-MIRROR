## 採用する最初のモデル

- 選択した年・区画・処理・年別Roundに該当する**記録行**を比較基準とする。
- イベント単位、非復元、固定件数の単純無作為抽出。調査回・区画・ペアを等確率で抽出するモデルではない。
- 整数の指定割合 `p` は0〜100%。件数は `k = floor((N*p+50)/100)`（0.5件は切り上げ）。
- PCG-XSH-RR 64/32と棄却法による整数乱数を使い、前方の部分Fisher–Yatesで選ぶ。
- 比較指標のノード集合は選択範囲の全記録で固定。分類は原ラベル、同値行は別記録。
- 比率・集計は正確な分数、標準偏差は分散の平方根として保存し、表示用近似を再現用データに混ぜない。

全観測記録は有限の比較基準であり、自然界の完全な真値ではない。割合は残す記録の指定値で、実際の調査時間や昆虫個体数を表さない。

宣言的fixtureは試験入力と期待値を簡略に表したもので、`RunResult`や実データのJSONスキーマそのものではない。全3,882件を検証するローダーへ架空の10行を渡す用途にも使わない。

既存の条件フォームは工程1・2の下書きで、現在の観測割合の下限は1%。**将来の接続時の仕様は0〜100%**とし、今回UIは変更しない。計算コアは工程6で実装済み、反復は工程7、可視化・結果の接続は工程8・9。
